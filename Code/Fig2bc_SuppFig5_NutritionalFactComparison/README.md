# Nutritional fact comparison analyses used for Figure 2b–c and Supplementary Figure 5.

## Script

`NutritionalFactComparison.R` — Compares compound composition with the nutritional facts listed in the product information.

## Input

- Concentration data prepared by `Code/1_ConcentrationTablePreparation.R`.
- Product information containing nutritional facts in `Data/Products.csv`.

## Usage

1. Run `Code/1_ConcentrationTablePreparation.R` to generate the prepared concentration data.
2. Run the nutritional fact comparison script in this directory.

## Output

Nutritional fact comparison results for Figure 2b–c and Supplementary Figure 5.

Additional manual modifications were made to prepare the figures for publication.
