# Compound composition analyses used for Figure 2a and related supplemental figures (SuppFig3, 4, and 16).

## Script

- `CompoundComposition.r`: Generates compound composition plots for Figure 2a and Supplementary Figures 3, 4, and 16.

## Input

Concentration data prepared by `Code/1_ConcentrationTablePreparation.R`.

## Usage

1. Run `Code/1_ConcentrationTablePreparation.R` to generate the prepared concentration data.
2. Run `CompoundComposition.r`.

The script uses shared paths configured in `Code/FilePath.R` and loads shared data and functions through `Code/Analysis_Utils.r`.

## Output

Plots for Figure 2a and Supplementary Figures 3, 4, and 16, saved to the repository’s `Figures/` directory.

Additional manual modifications were made to prepare the figures for publication.
