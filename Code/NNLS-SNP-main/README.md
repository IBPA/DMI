# NNLS-SNP-main

Packaged NNLS-SNP breed/variety composition estimator module and source code.

## Documentation

- Full documentation for this module is available at: https://github.com/IBPA/NNLS-SNP
- The reference allele frequency file extracted from the BGVD database can be made available upon request.

## Subdirectories

- `NNLS-SNP-main/`

## Usage

Run scripts in this folder as part of the corresponding figure workflow, using shared paths configured in `Code/FilePath.R` where applicable.
